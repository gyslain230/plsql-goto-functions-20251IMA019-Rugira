## Overview
This repository contains the practical SQL scripts and PL/SQL blocks for Individual Assignment III. It demonstrates the use of GOTO statements, logical loops, standalone stored functions, and proper exception handling within Oracle Database 21c.

## How to Run
1. Run `00_setup/create_tables.sql` to initialize the `employees` and `departments` schema.
2. Compile all functions inside the `02_functions/` directory.
3. Run the GOTO logic blocks in `01_goto/`.
4. Execute the tests in `03_tests/` to verify outputs.
